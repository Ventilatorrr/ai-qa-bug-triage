# User Stories

## Increment 1 — User & Project Management

### US-001 — Register an Account

As a new user, I want to register an account so that I can access the system.

### US-002 — Log In

As a registered user, I want to log in so that I can access the system.

### US-003 — Log Out

As an authenticated user, I want to log out so that I can end my session securely.

### US-004 — Create a Project

As an authenticated user, I want to create a project so that I can manage bugs within it.

### US-005 — Manage Projects

As a Project Owner, I want to view, open, edit, and delete my projects so that I can manage them effectively.

### US-006 — Manage Project Members

As a Project Owner, I want to add and remove project members so that I can control who has access to the project.

---

## Increment 2 — Bug Management

### US-007 — Create a Bug Report

As a QA Analyst, I want to create a bug report so that I can record and track a software defect.

### US-008 — Manage Bug Reports

As an authorized project member, I want to view, edit, and delete bug reports so that I can maintain accurate project information and manage defects effectively.

### US-009 — Assign Bugs

As a QA Analyst or Project Owner, I want to assign bugs to Developers so that responsibility for fixing defects is clear.

### US-010 — Manage Bug Status

As a QA Analyst or Developer, I want bugs to progress through a defined lifecycle so that their current state is clear.

### US-011 — Search and Filter Bugs

As a project member, I want to search and filter bug reports so that I can quickly find relevant defects.

---

## Increment 3 — AI-Assisted Bug Triage

### US-012 — Request AI Triage

As a QA Analyst, I want to request AI-assisted triage for a bug so that I can receive suggestions that may help with the triage process.

### US-013 — Review AI Suggestions

As a QA Analyst, I want to review, modify, accept, or reject AI suggestions so that I remain in control of the final bug information.

### US-014 — Control AI Tool Access

As a QA Analyst, I want AI tools to be restricted to authorized capabilities so that AI actions cannot perform unauthorized operations.
