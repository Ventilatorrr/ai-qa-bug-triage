About AI QA Bug Triage

A web application for managing projects and bugs with AI-assisted triage.

Project and Bug Management

The application allows teams to organize projects, report and track defects, assign bugs to team members, and manage their severity, priority, and status. Role-based permissions help ensure users can perform actions appropriate to their responsibilities.

AI-Assisted Bug Triage

AI Assist helps improve bug report quality by suggesting clearer descriptions, reproduction steps, expected and actual results, and appropriate severity and priority levels.

Each suggestion can be reviewed, applied, or dismissed individually. AI suggestions are never saved automatically. Users remain in control of the final bug report.

About the Project

This application is a software quality assurance portfolio project, built to demonstrate practical QA methodologies, requirements traceability, defect management, API and UI testing, performance testing, and test automation.

It focuses on core defect-management workflows. Additional features found in larger issue-tracking systems, such as attachments and comments, are not implemented.

Testing & Quality Assurance

Requirements and acceptance criteria are traced to test cases. Automated regression testing includes pytest API, database and mocked-AI tests, JavaScript tests, and Playwright with BDD scenarios, executed through GitHub Actions. Additional QA evidence includes Postman API regression, JMeter performance checks and reviewed real-model AI evaluations.
